
# 🪑 **FurniCraft – Modern Furniture E-Commerce Web App**

A fully responsive and modern furniture shopping web application built using **React.js**, featuring dynamic UI components, category-based filtering, product details pages, and a fully functional shopping cart with **LocalStorage support**.

---

## 🚀 **Live Demo**

👉 **Live Hosted Link:* https://furniture-web-123.netlify.app/* 

---


## 🛠️ **Tech Stack**

| Layer                | Technologies                             |
| -------------------- | ---------------------------------------- |
| **Frontend**         | React.js, JavaScript (ES6+), HTML5, CSS3 |
| **Styling**          | Tailwind CSS / Custom CSS                |
| **State Management** | React Hooks + LocalStorage               |
| **Routing**          | React Router                             |
| **Build Tool**       | Vite                                     |

---

## ⭐ **Key Features**

### 🛒 Shopping Experience

* Add to cart / Remove from cart
* Real-time cart count
* Dynamic price calculation
* Persistent cart stored in LocalStorage

### 🎨 UI & UX

* Premium modern furniture UI
* Responsive design (Mobile → Desktop)
* Smooth animations & hover effects
* Clean component architecture

### 🔎 Product Browsing

* Search furniture by name
* Filter by category
* Product detail popup/card
* High-quality product images

## ⚙️ **Installation & Setup**

```bash
# Clone the repository
git clone https://github.com/USERNAME/FurniCraft-Furniture-App.git

# Navigate to folder
cd FurniCraft-Furniture-App

# Install dependencies
npm install

# Start the development server
npm run dev
```
